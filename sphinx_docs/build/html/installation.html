Installation

We strongly recommend installing condynsate in a virtual environment:

C:\Users\username> python -m venv .venv
C:\Users\username> .venv\Scripts\activate.bat

When done installing and using lepton, deactivate the virtual environment with:

(.venv) C:\Users\username> deactivate

From PyPi (Recommended)

python>=3.12 and pip are required.

To install condynsate:

(.venv) C:\Users\username> pip install lepton-pt

From Source

python>=3.12, pip, and git are required.

To clone the repository:

(.venv) C:\Users\username> git clone https://github.com/GrayKS3248/Lepton3.5_Purethermal3.git
(.venv) C:\Users\username> cd Lepton3.5_Purethermal3

To install:

(.venv) C:\Users\username\Lepton3.5_Purethermal3> pip install -e .
